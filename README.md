# Liza Hamadi | Web Developer Portfolio

Hand-coded with HTML, CSS and JavaScript. No frameworks, no build step.

## Edit
- `script.js`: your projects are in the `PROJECTS` list at the top. Only `title`, `summary` and `tags` are required; every other section (screens, purpose, challenge, role, highlights, flows, tools, outcome) is optional and only appears if you fill it in. Images go in `images/`, e.g. `cover: "images/project-one.png"`.
- `index.html`: search for `EDIT` to fill in your story, experience, skills, email and links.
- `style.css`: colours are at the top.

## Publish on GitHub Pages
1. Create a public repo named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder (plus `resume.pdf`).
3. Settings > Pages > Deploy from a branch > `main` / root > Save.
4. Your site is live at `https://YOUR-USERNAME.github.io` a minute later.
